# README and public docs

- **The README is a landing page** for someone who just arrived, as short as a well-known AI
  open-source project's: hero, quick start in one block, each feature as a short text with an
  image, a short list, requirements and FAQ in `<details>`, links. Many images. Anything longer
  goes to `docs/how-it-works.md`.
- **The text names no seed bot and counts none** ("starter bots", "a bot"): seeds are renamed,
  dropped and switched off, and a name in the text soon lies. Images show real seed faces and names,
  but no value that moves, such as a connector count or a tool name.
- `README.ko.md` changes with `README.md`, in the same structure.
