## 말을 거는 첫 하네스

올해 에이전트 하네스는 정말 좋아졌다. Claude Code, OpenClaw, Hermes — 전부 읽고 타이핑한다. 그리고 아주 잘한다. **다만 아무도 듣지는 않는다.**

음성은 텍스트 에이전트에 씌우는 껍데기가 아니다. 하네스가 하는 단 하나의 일 — 긴 루프를 돈다 — 를 정면으로 깨기 때문이다. 브라우저를 여는 음성 모델은 90초를 조용히 있는다. 조용한 통화는 죽은 통화다. 아무도 수화기를 들고 침묵을 견디지 않는다.

그래서 Thursday 는 **한 통화에 두 종류의 머리**를 둔다.

실시간 음성 모델이 대화를 잡고, 한눈에 답할 수 있는 것만 만진다 — 나에 대해 기억하는 것, 파일 하나, 명령 한 줄. 그보다 느린 건 전부 **봇**에게 넘긴다. 컴퓨터 전체를 가진 텍스트 모델이 뒤에서 돌고, 끝나면 한 문장으로 돌아와 그녀가 소리 내어 말해준다.

기다릴 일이 없다. 그냥 계속 이야기하면 된다.

```
나 ──▶ Thursday ──delegate──▶ 봇 ──▶ 셸 · 브라우저 · 파일 · MCP
        (초 단위)                     (분 단위, 전화를 끊어도
       계속 대화 ◀──report──           계속 돈다)
```

## 설치

```bash
npx thursday-agent
```

`localhost:3000` 에서 열린다. 통화를 여는 데 키 하나 — OpenAI 나 xAI 키를 첫 화면에 입력. 채울 `.env` 도, 만들 계정도, 건드릴 설정 파일도 없다. 데이터는 `~/.thursday` 에 산다.

<details>
<summary>소스에서</summary>

```bash
git clone https://github.com/cgoinglove/thursday.git
cd thursday
pnpm install
pnpm dev
```

Node 22.18+, pnpm 10+. 첫 실행 때 봇이 쓸 브라우저(~280 MB)를 백그라운드에서 받는다.

</details>

macOS 에서 만들었다. Linux 는 될 것이고, Windows 는 확인하지 않았다.

## 이렇게 말해보세요

첫 10분, 순서대로. 각각이 다른 부분을 보여준다.

| 말 | 일어나는 일 |
|---|---|
| "Hey Thursday." | 통화가 열린다. 첫 통화에서는 뭐라고 부를지 묻고, 기억한다. |
| "이번 주에 뭐 받았지?" | 명령 하나, 말하는 사이에 끝난다. 셸은 그녀가 직접 쓰는 것이지 넘기는 일이 아니다. |
| "우리 언니 생일 3월 3일인 거 기억해." | 그 자리에서 저장된다. 다음 주에 물어보면 된다. |
| "다음 주 교토 가는데 20만원 아래 코트 찾아서 한 페이지로 정리해줘." | **Navigator** 가 진짜 브라우저로 쇼핑몰을 연다. 그동안 그녀는 나와 계속 이야기한다. 끝나면 페이지가 화면에 저절로 열린다. |
| "집주인한테서 온 메일 있어?" | **이미 로그인돼 있는** 내 크롬에 그대로 붙는다. 연결할 것도, OAuth 절차도 없다. |
| "내 봇들이 쓸 구글 계정 하나 만들어줘." | **Jarvis** 가 내가 볼 수 있는 창에서 폼을 채우고, 비밀번호 앞에서 멈춘다. 그 절반은 내 몫. 그다음 이어서 한다. |
| "오늘 정한 거 한 장으로 정리해줘." | **Scribe** 가 무엇에 쓸 건지 묻고 쓴다. 채팅 말풍선이 아니라 문서로 열린다. |
| "Crumb 이라는 빵집 로고 그려줘." | 스튜디오: 이미지·영상·음성·받아쓰기를, 이미 가진 키로. |

그리고 끊으면 된다. 작업은 나 없이 끝나고, 다음 통화에 말해준다 — 허락하면 먼저 전화를 걸기도 한다.

## 로컬 퍼스트, 그리고 여기선 그게 훨씬 중요하다

프라이버시를 말하지 않는 에이전트는 없다. 하지만 브라우저를 모는 음성 에이전트에게 "로컬"은 프라이버시 체크박스가 아니라, **애초에 이게 되게 만드는 유일한 방법**이다.

- **내 브라우저, 내 로그인.** 클라우드 에이전트는 내 메일을 읽을 수 없다. 내가 아니니까. Thursday 의 봇은 내 책상에 이미 열려 있는 크롬에 붙는다 — 내 세션, 내 쿠키, 이미 끝난 2FA. 외부에 맡길 수가 없는 종류의 일이 통째로 가능해진다.
- **내 컴퓨터.** 봇이 내 진짜 파일에 진짜 명령을 돌린다. 사본을 올린 샌드박스 VM 이 아니다.
- **내 키**는 내 디스크의 SQLite 에 있고, 내가 고른 제공자에게만 간다. 봇의 셸 환경변수에서는 아예 지워지므로, 털린 npm 패키지가 읽어갈 수 없다.
- **내 메모리**는 디스크의 평범한 노트다. 한 줄에 사실 하나. 아무 에디터로나 열어보고, 지우고 싶으면 지운다.
- **계정도, 텔레메트리도, 우리 서버도 없다.** "서버"는 내 노트북에서 도는 Node 프로세스고, `127.0.0.1` 에 묶여 있다.

정직하게: **지능은 원격이다.** 통화를 맡길 만한 로컬 실시간 음성 모델이 아직 없어서 음성은 OpenAI 나 xAI 로 간다. 나머지 — 파일, 브라우저, 메모리, 작업 — 는 기계 밖으로 나가지 않는다. 로컬 음성 모델이 나오는 날, 준비돼 있는 앱은 이거다.

## 어떻게 돌아가나

!![design: 브랜드 캔버스의 `How it works` 아트보드를 1200×560 으로 내보내 `docs/images/how-it-works.png` 로]

- **통화는 실시간 음성 모델이다.** OpenAI Realtime 또는 xAI Grok Voice — 대화 전체를, 어떤 언어로든, 끼어들기까지.
- **봇은 컴퓨터 전체를 가진 텍스트 모델이다.** 셸, 진짜 브라우저(Playwright), 파일시스템, 스킬, MCP 서버, 그리고 서로. 로그인이 필요하면 내 눈앞의 창에서 하고, 일을 끝까지 가져간다: 산 물건, 만든 계정, 지은 페이지.
- **작업은 통화보다 오래 산다.** 탭이 아니라 서버에서 돈다. 일하는 중에 끊어도 계속 간다.
- **메모리는 노트 폴더고, 스스로 정리된다.** 답하기 전에 읽고, 뭔가 나오는 순간 적는다. 그리고 통화가 끝나면 텍스트 모델이 실제로 오간 말을 다시 읽고 노트와 맞춘다 — 말하는 도중에 적어둘 생각을 못 한 것까지 남는다.

각 부분이 무엇을 만지고 무엇을 만지지 않는지, 긴 버전: [docs/how-it-works.md](docs/how-it-works.md)

## 같이 오는 것

**봇 셋.** 주제가 아니라 성향으로 나눴다 — Jarvis 는 계획하고 남은 걸 다 하고, Navigator 는 가서 보고, Scribe 는 쓴다. 내 봇은 1분이면 만든다: 이름, 한 문장, 원하면 모델과 고정 툴 몇 개.

**스킬** — 봇이 시작 전에 읽는 방법서: [브라우저](skills/browser/SKILL.md), [이 Mac](skills/computer/SKILL.md), 그림이나 조작이 필요한 결과를 위한 [인터랙티브 페이지](skills/interactive-page/SKILL.md), 그리고 스킬을 늘리는 둘 — [스킬 찾기](skills/find-skills/SKILL.md), [스킬 만들기](skills/skill-creator/SKILL.md). 오픈 스킬 생태계의 무엇이든 `npx skills add` 로 설치된다.

**커넥터 46개, 각각 클릭 한 번** — Notion, GitHub, Linear, Slack, Figma, Stripe, Supabase, Cloudflare, Sentry 등 — 여기에 직접 붙여넣는 MCP 서버까지. OAuth 는 알아서 처리하고, 봇이 툴을 검색해서 부른다. 봇에 몇 개 고정해두면 검색을 건너뛴다.

## 모델

| | 제공자 |
|---|---|
| **음성** (통화) | OpenAI Realtime · xAI Grok Voice |
| **텍스트** (봇) | OpenAI · Anthropic · Google · xAI · Vercel AI Gateway (실리는 모델 전부, 실시간 목록) |
| **스튜디오** | OpenAI · Google · xAI · Vercel AI Gateway |

시작은 키 하나로 충분하다 — 음성 키는 텍스트 키이기도 하다. 설정에서 더 넣으면 봇마다 다른 모델로 돌릴 수 있다.

## 어디로 가나

**0.x** 는 이 웹 앱이다. 하네스를 더 — 더 나은 봇, 더 많은 스킬, 더 넓은 스튜디오, 그리고 실제로 그녀에게 말을 걸어본 첫 사람들이 요청하는 것들.

**1.0** 은 데스크톱 앱이다 — 같은 서버를 창 하나에, 마이크와 컴퓨터를 한 걸음 더 가까이.

그녀에게 뭐라고 말했고 어디서 멈췄는지 알려주면 된다. 그게 로드맵이다.

## 보안

이 앱은 셸과 브라우저와 내 키를 가진 언어 모델이다. 사고가 아니라 그게 제품이다. 키는 셸에 닿지 않고, 쓰기는 워크스페이스 안으로 제한되고, 서버는 localhost 전용이고, 비밀번호·일회용 코드·패스키는 내가 친다. 이게 무엇을 막고 무엇을 막지 않는지: [SECURITY.md](SECURITY.md)
